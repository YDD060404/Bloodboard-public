# Bloodboard 统一版 0.2.0

桌面、独立网页、联网服务器和 Match Lab 使用同一份核心源码。保留云端 Glotl 修复、联网动画、断线恢复、完场归档、中英文、键盘与横竖屏，加入本地精确球链和状态键优化。

运行：Node.js 18+ 下执行 `npm ci`、`npm run build`、`npm start`，打开输出的本地地址。`dist/web` 也可独立离线使用。线上地址为 https://bloodboard-match.onrender.com/ ，实际部署版本以该站 build-info 为准。

AI保留 Balanced、冻结的 Hopeful 1.5.9，以及单独标识的 S4.37U 兼容版。兼容版未改训练权重，不代表重新训练或实力升级。未经验收的 S4.38–S4.41 不纳入发布。

升级保留旧安装作为回滚，不清除球队、残局、设置、浏览器重连令牌或云端日志。新规则指纹要求联网双方同步；历史记录可能显示来自其他规则代码。完整验收结果见独立发布报告；本地双浏览器测试不等于两台物理设备跨网络验收。
